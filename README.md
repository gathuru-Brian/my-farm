# Kuria Farms Website

A simple website for Kuria Farms showcasing products, services, and contact information.

## Overview

- Responsive design for desktop and mobile.
- Clean layout focused on agriculture, produce, and farm services.
- Easy to update and extend.

## Features

- Home section with farm introduction.
- Product showcase.
- Service offerings.
- Contact information and inquiry form.

## Getting Started

1. Clone the repository.
2. Open the project folder in your code editor.
3. Run a local development server or open the HTML files directly.
